FULL INSTRUCTIONS:  cat ccdc/HOW-TO-RUN.txt       how to run it, start to finish
EVERY COMMAND:      cat ccdc/COMMANDS.txt        complete reference, nothing omitted
EVERY SCRIPT:       bash <script> --help          works on all of them
PER-BOX FOLDERS:    debian/ arch/ rocky/ ubuntu/ tinycore/  (each has run.sh + RUN.txt)

RUN IT
  sudo bash ccdc/go d      DRY RUN first - prints what it would do, changes nothing
  sudo bash ccdc/go r      recon only - inventory, backup, red-flag scan
  sudo bash ccdc/go        full guided run (asks before every change)

NEVER run this on tweety (.1/.2, OPNsense router). See OPNSENSE.md. A reset is -100 points.

GET IT ONTO A BOX (pick one)
  scp:   scp ccdc.tgz user@192.168.220.11:    then:  tar xzf ccdc.tgz && sudo bash ccdc/go d
  http:  on your VPN machine, in the folder with ccdc.tgz:   python3 -m http.server 8000
         on the box:  curl -O http://YOURIP:8000/ccdc.tgz && tar xzf ccdc.tgz && sudo bash ccdc/go d
  git:   git clone URL ccdc && sudo bash ccdc/go d

KEEPING SERVICES UP (the thing that protects your score)
  sudo bash ccdc/services.sh discover    build watch list
  sudo bash ccdc/services.sh check       one-shot health check
  sudo bash ccdc/services.sh watch 30 &  auto-restart dead services
  sudo bash ccdc/services.sh status      restart counts + log

IF THE MAIN KIT WILL NOT RUN
  cat ccdc/plan-b/PLAN-B.txt
  Five standalone /bin/sh scripts, numbered in the order to run them.
  Quick version:
    sudo sh ccdc/plan-b/1-look.sh            see the box (read only)
    sudo sh ccdc/plan-b/5-hunt.sh            find red team (read only)
    sudo sh ccdc/plan-b/2-pw.sh bob          change one password
    sudo sh ccdc/plan-b/3-keep.sh 80 443 &   keep services up
    sudo sh ccdc/plan-b/4-wall.sh 22 80 443  firewall, self-undoing

TYPING TIPS
  Tab completion:  sudo bash cc<TAB>/go
